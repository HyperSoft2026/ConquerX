# ConquerX Audio

The final audio pack for ConquerX is designed as **original, game-specific audio** rather than copied music or sound effects from commercial games.

## Included production sounds

- `ui_click.wav` — interface click
- `kill.wav` — elimination confirmation
- `death.wav` — player defeat cue
- `victory.wav` — match victory cue
- `territory.wav` — territory capture cue
- `music_loop.wav` — short original ambient gameplay loop

These sounds are generated specifically for ConquerX and are not sourced from a third-party sample library.

## Replacement policy

If a future release replaces any file with a third-party licensed asset, keep the license text, creator attribution, source URL and license version in this directory before shipping the asset.

Do not commit copyrighted music, ripped game sounds, or assets whose commercial/mobile redistribution rights are unclear.
